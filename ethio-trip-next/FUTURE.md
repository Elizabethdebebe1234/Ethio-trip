# Future Improvements and Known Limitations

## Known Limitations

- Some destination information and accommodation prices are sample planning data rather than live prices.
- Travel suggestions do not necessarily include travel time between destinations.
- Browser-based trip history does not automatically synchronize across devices.
- CSV reports contain the itinerary data available in the browser at the time of export.
- Authentication currently uses configured credentials rather than a complete user registration and account management system.
- Performance results need to be measured and recorded using a consistent testing process.

## Planned Improvements

### Data and Trip Management

- Add persistent, account-linked trip storage.
- Allow users to access saved itineraries across devices.
- Improve trip request management and status tracking.

### Authentication and Security

- Add secure account registration and password management.
- Improve session expiration and revocation.
- Add server-side authorization checks to all protected operations.

### Travel Planning

- Include estimated travel times between destinations.
- Add more Ethiopian destinations and richer destination information.
- Provide more detailed budget planning and accommodation options.

### Performance and Accessibility

- Measure performance using Lighthouse.
- Optimize images and client-side JavaScript.
- Improve keyboard navigation, accessibility, and error handling.

### Future Integrations

- Explore reliable travel information APIs.
- Investigate live accommodation and transport information where suitable data sources are available.
